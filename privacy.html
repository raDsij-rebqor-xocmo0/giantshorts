Privacy Policy

Last updated: November 26, 2026

Giant Shorts is a personal tool used only by its owner to upload their own videos to their own TikTok account.

Data we access

With your permission via TikTok Login Kit, the tool receives an access token and basic profile information (open ID, display name) solely to upload videos you choose to your TikTok drafts.

Storage

Tokens are stored only on the owner's local computer. No data is sent to any server other than TikTok's official API. No data is sold, shared or used for advertising.

Deletion

You can revoke access at any time in TikTok settings (Security → Manage app permissions). Local tokens can be deleted by removing the token file.

Contact

Questions can be raised via the GitHub repository hosting this page.
